# Lower Azurelake Ward runtime asset slots

The subsection is playable with procedural Phaser stand-ins while the final transparent PNG pieces are produced from `lower-ward-asset-manifest.json` in the assigned Google Drive folder.

Canonical naming:

- Asset ID: `azurelake.lower-ward.<category>.<asset-name>.<variant>`
- Filename: `azurelake__lower-ward__<category>__<asset-name>__<variant>.png`

The Drive style-guide filename currently says `lower-azureland-ward-style-guide.png`; this is preserved as source evidence only. Runtime IDs and paths use the established region name `azurelake`.

Final art must use the approved painterly non-pixel 3/4 character-scale camera. It must not contain baked collision, UI, readable labels, player sprites or unrelated scenery. Phaser remains authoritative for collision, services, entrances and depth sorting.
